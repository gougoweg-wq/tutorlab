# Модель усвоения

Цель: для каждой пары (ученик, тема) получить число `mastery ∈ [0,100]`, которому можно верить, и из него вывести слабые темы, риск забывания и рекомендацию «что дальше». «Средний балл» не подходит: он не учитывает сложность заданий, давность и объём данных.

## 1. Латентный уровень: Elo-подобное обновление

Для ученика `s` и темы `t` храним уровень `θ_{s,t}` (старт 0). Для вопроса `q` храним сложность `δ_q` (старт из ручной шкалы 1..5: `δ = (difficulty − 3) · 0.8`, то есть −1.6 … +1.6).

Вероятность верного ответа (логистическая модель, 1PL/Rasch):

```
P = 1 / (1 + exp(−(θ − δ)))
```

После ответа `y ∈ {0,1}` (для частичных баллов `y = score / max_score`):

```
θ ← θ + K_s · (y − P)
δ ← δ − K_q · (y − P)
```

Шаг обучения убывает с числом наблюдений, чтобы первые ответы двигали уровень сильно, а сотый — слабо:

```
K_s = 0.9 / sqrt(1 + n_{s,t} / 4)      n — число ответов ученика по теме
K_q = 0.3 / sqrt(1 + m_q / 10)         m — число ответов на вопрос во всём воркспейсе
```

Ответ по вопросу с несколькими темами обновляет каждую тему с весом `is_primary ? 1 : 0.5`. Родительская тема получает обновление с весом 0.5 (агрегат по разделу), не выше одного уровня вверх.

## 2. Затухание по времени

Знание забывается. Эффективный уровень на момент `now`:

```
τ = 21 дней (период полураспада)
age = now − last_attempt_at
θ_eff = θ · 0.5^(age / τ)
```

Затухание к нулю (середине шкалы), а не в минус: давно не повторявшаяся сильная тема становится «неизвестной», а не «слабой». Отдельно помечаем **риск забывания**: `θ > 1.0` (mastery была > 73) и `age > 14 дней`.

## 3. Mastery и доверительный интервал

```
mastery = round(100 · σ(θ_eff)),  σ(x) = 1/(1+e^{−x})
```

Неопределённость от объёма данных (приближение стандартной ошибки Rasch-оценки):

```
se = 1.2 / sqrt(max(n, 1))
ci_low  = 100 · σ(θ_eff − 1.96·se)
ci_high = 100 · σ(θ_eff + 1.96·se)
```

Правило интерпретации:

| Условие | Статус |
|---|---|
| `n < 4` | «мало данных» (серый), тема не считается слабой |
| `ci_high < 60` | слабая (красный) |
| `ci_low > 80` | сильная (зелёный) |
| иначе | в работе (жёлтый) |

Пороги вынесены в конфиг `modules/mastery/config.ts`.

## 4. Производные показатели

- **Топ-5 слабых:** среди тем с `n ≥ 4` сортировка по `ci_high` возрастанию, потом по числу неверных за 14 дней.
- **Топ-5 сильных:** сортировка по `ci_low` убыванию.
- **Риск забывания:** см. §2, сортировка по `age`.
- **Скорость роста:** наклон линейной регрессии `mastery(t)` по `mastery_events` за 4 недели, в пунктах в неделю.
- **Динамика ученика:** средневзвешенная mastery по темам, вес = число заданий в теме за окно, по неделям, 4 и 12 недель.

## 5. Рекомендация «что дальше»

Вход: ученик, цель (school/exam/sat), опционально предмет. Алгоритм:

1. Кандидаты — темы предмета для класса ученика и ниже.
2. Отсекаем темы, у которых есть предпосылка с `mastery < 60` и `n ≥ 4` (граф `topic_prereqs`): сначала закрываем фундамент. Если отсечено всё, рекомендуем саму слабую предпосылку.
3. Скор кандидата:
   ```
   score = 0.5 · (100 − mastery)          насколько слабая
         + 0.2 · min(n, 8) / 8 · 100      достаточно ли данных, чтобы это была не случайность
         + 0.2 · forgetting_risk · 100    пора повторить
         + 0.1 · due_review · 100         подошёл интервал SM-2
   ```
4. Верхние 3 темы → предложение: «следующий урок: …», плюс кнопка «тренировочный набор» → blueprint: 10 заданий, 6 из первой темы, 4 из второй, сложность вокруг текущего уровня (`δ ≈ θ_eff ± 0.5`), чтобы P верного ответа была около 0.6–0.7 — зона продуктивной трудности.

## 6. Интервальное повторение (SM-2, упрощённый)

По завершении попытки для каждой темы с `n ≥ 4`:

```
q = 5 · (доля верных в этой попытке по теме)     оценка 0..5
если q < 3:  repetitions = 0, interval = 1
иначе:       interval = [1, 6, prev·ease][min(repetitions, 2)], repetitions += 1
ease = max(1.3, ease + 0.1 − (5 − q)·(0.08 + (5 − q)·0.02))
due_at = now + interval дней
```

Темы с `due_at ≤ now` попадают в «повторить» в ленте ученика и в рекомендации (§5, слагаемое `due_review`).

## 7. Прогноз SAT

Для секции (Math, RW) считаем средневзвешенную mastery по её доменам с весами digital SAT (Math: Algebra 35%, Advanced 35%, Problem Solving 15%, Geometry/Trig 15%; RW: Craft 28%, Information 26%, Standard English 26%, Expression 20%). Линейная карта `mastery → шкала 200–800`:

```
score = 200 + 6 · mastery_section
```

Интервал: `± (40 + 200 · mean_se)`. В интерфейсе всегда с подписью «оценка по темам, а не по тесту; ±N баллов». Калибровка по реальным пробникам — после MVP (BACKLOG).

## 8. Тест-план модели (unit, синтетика)

1. Ученик отвечает верно на 10 вопросов сложности 3 → mastery > 75, `ci` сужается монотонно.
2. 10 неверных → mastery < 25.
3. Чередование верно/неверно на сложности 3 → mastery в 40–60.
4. Верно на сложности 5 двигает θ сильнее, чем верно на сложности 1 (при равных n).
5. После 42 дней без активности mastery с 90 падает ниже 65, статус «риск забывания», не «слабая».
6. `n = 2` никогда не даёт статус «слабая».
7. Рекомендация не предлагает тему, чья предпосылка слабая; предлагает предпосылку.
8. SM-2: три верные попытки подряд дают интервалы 1, 6, ~15 дней.
9. Пересчёт из `mastery_events` с нуля даёт те же значения, что инкрементальный (идемпотентность).
